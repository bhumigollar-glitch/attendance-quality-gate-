Quality Gate Ingestion Policy

Deterministic quality enforcement before downstream reporting.

🛡️ Acceptance Policy: A spreadsheet is classified as ACCEPTED only when it passes all blocking rules. Any blocking failure immediately triggers QUARANTINE.

🧹 Conservative Cleaning: Accepted uploads undergo deterministic cleaning (whitespace trimming, ISO-8601 date formatting, status case normalization). Missing fields are never synthesized.

🔒 Quarantine Protection: Quarantined files are strictly barred from the cleaned download endpoint (HTTP 403 Forbidden).

🔖 Rule Versioning: Validation results are immutable and permanently tagged with the exact rule version used.
